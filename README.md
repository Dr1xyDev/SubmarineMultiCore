# 🌊 SubmarineMultiCore

🚀 SubmarineMultiCore es un núcleo multiversión para servidores Minecraft Bedrock, diseñado para permitir la conexión de diferentes versiones del juego en un mismo servidor.

---

⚙️ Información del Proyecto

- 👨‍💻 Desarrolladores del API:
  SubmarineTeam / SubTeam

- 🌐 Multiversión soportada:
  "1.1.0 → 1.21.120"
  (Se pueden agregar más versiones modificando el núcleo)

- 🐘 PHP requerido: "8.3"

- 🧩 API: "3.28.1"

---

📂 Estructura básica

bin/
src/
vendor/
start.sh

---

⚠️ Problemas con permisos en Panel Pterodactyl

Si tienes problemas de permisos en Panel Pterodactyl, descarga el archivo:

Pterodactyl-Bin+phar.tar.gz

desde este repositorio.

Luego:

1️⃣ Súbelo a los archivos de tu servidor
2️⃣ Descomprímelo en el directorio del servidor
3️⃣ Obtendrás el backup completo:

- 📦 Binario
- 📦 PocketMine-MP.phar

Listo para ejecutarse nuevamente.
